# 发现设备

扫描页同时开启**三路发现通道**，设备从哪一路出现取决于它的机型与当前状态。列表统一展示：机型、通道、信号强度（RSSI）、最近在线时间，支持分页与过滤。

| 通道 | 面向机型 | 前置条件 | 适用场景 |
| ---- | ---- | ---- | ---- |
| **BLE 广播扫描** | NE101（NE301 计划中） | 电脑蓝牙适配器可用 | 产线 / 现场批量配网，设备无需入网 |
| **softAP SSID 扫描** | NE101、NE301 | 电脑有 WLAN 网卡 | 单台配置；设备热点直连 |
| **局域网发现（CT-Disc）** | NE503 | 电脑与设备同网段 | 已入网设备的管理入口 |

## BLE 广播扫描

设备处于配置模式时会以 BLE 广播播报自身（机型代号、地址后缀与可配置标志）。NeoLinker 持续扫描并在列表中汇总：

- **信号强度（RSSI）**可辅助判断距离——越近越稳；
- 广播中的 **BUSY / 可配置标志**会体现在列表状态里（他机正在配置时设备会示忙）；
- 设备离线后从列表淡出，保留**最近在线**时间；
- 注意**配置窗口**：设备上电后约 60 秒内可被配置（指示灯蓝色快闪），约 1 分钟无操作会自动休眠——短按配置键唤醒后重试。

## softAP SSID 扫描

设备置于配置模式后会开出热点：目标 SSID 约定为 `CT-AP-<地址后缀>`，当前 NE101 固件仍沿用旧式 `<机型>_<地址后缀>`（如 `NE101-P_BBC6DC`），两种前缀都需要认识。NeoLinker 扫描 WLAN 里的这类 SSID 并列出。选定设备后，**应用会自动连接设备热点**（期间断开当前 Wi-Fi，配置结束后自动恢复），随后走与 BLE 相同语义的配置会话（CT-Prov over HTTP）。

常见机型的 softAP 默认地址：

| 机型 | softAP 默认地址 |
| ---- | ---- |
| NE101 | `192.168.1.1` |
| NE301 | `192.168.10.10` |
| NE503 | `10.0.0.1`（协议预留；NeoLinker 不经 softAP 支持 NE503） |

## 局域网发现（CT-Disc）

NE503 入网后每隔数秒在局域网内组播 `ct-announce`（含序列号、IP、端口与能力）。只要电脑与设备**在同一网段**，扫描页的 LAN 一路就会列出它。发现后可在应用内直接打开其管理页进行管理（NE503 暂不提供配置会话）。

## 过滤与扫码录入

- **机型 / 通道过滤**：列表上方按机型与通道筛选，产线上只看目标机型；
- **扫码添加设备**：点扫码入口，用电脑摄像头扫描设备随附的二维码，或直接上传二维码图片，快速定位目标设备。

## NE503 内嵌管理页

对经 LAN 发现的 NE503，列表操作里有**打开管理页**：设备的管理页在应用内（WebView2）直接打开，无需浏览器、无需手输 IP。
