# 发现设备

扫描页同时开启**三路发现通道**，设备从哪一路出现取决于它的机型与当前状态。列表统一展示：机型、通道、信号强度（RSSI）、最近在线时间，支持分页与过滤。

| 通道 | 面向机型 | 前置条件 | 适用场景 |
| ---- | ---- | ---- | ---- |
| **BLE 广播扫描** | NE101（NE301 计划中） | 电脑蓝牙适配器可用 | 产线 / 现场批量配网，设备无需入网 |
| **softAP SSID 扫描** | NE101、NE301 | 电脑有 WLAN 网卡 | 单台配置；设备热点直连 |
| **局域网发现（CT-Disc）** | NE503 | 电脑与设备同网段 | 已入网设备的管理入口 |

## BLE 广播扫描

设备处于配置模式时会以 BLE 广播播报自身（机型代号、地址后缀与可配置标志）。NeoLinker 持续扫描并在列表中汇总：

- **信号强度（RSSI）**可辅助判断距离——越近越稳；
- 广播中的 **BUSY / 可配置标志**会体现在列表状态里（他机正在配置时设备会示忙）；
- 设备离线后从列表淡出，保留**最近在线**时间。

## softAP SSID 扫描

设备置于配置模式后会开出热点，SSID 约定为 `CT-AP-<地址后缀>`。NeoLinker 扫描 WLAN 里的这类 SSID 并列出。选定设备后，按应用指引把电脑 Wi-Fi 切到设备热点，即可走与 BLE 相同语义的配置会话（CT-Prov over HTTP）。

常见机型的 softAP 默认地址：

| 机型 | softAP 默认地址 |
| ---- | ---- |
| NE101 | `192.168.1.1` |
| NE301 | `192.168.10.10` |
| NE503 | `10.0.0.1`（一般经 LAN 通道使用） |

## 局域网发现（CT-Disc）

NE503 入网后每隔数秒在局域网内组播 `ct-announce`（含序列号、IP、端口与能力）。只要电脑与设备**在同一网段**，扫描页的 LAN 一路就会列出它。发现后可直接进入配置会话，或在应用内打开其管理台。

## 过滤与扫码录入

- **机型 / 通道过滤**：列表上方按机型与通道筛选，产线上只看目标机型；
- **扫码录入**：点扫码入口，用电脑摄像头扫描设备随附的二维码，或直接上传二维码图片，快速定位目标设备。

## NE503 内嵌管理台

对经 LAN 发现的 NE503，列表操作里有**打开管理台**：设备的管理页在应用内（WebView2）直接打开，无需浏览器、无需手输 IP。
