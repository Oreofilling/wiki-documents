# 回执与历史

NeoLinker 把"配置过什么、什么时候配的"作为一等公民：**每一次完成的会话都留痕**。

## 设备回执

交付成功后，结果页给出本次会话的**纯文本回执**，按设备组织，内容包括：

- 设备标识（机型 / 序列号等）；
- 本次写入的各配置节；
- 写入（应用）时间与持久化计数。

回执可以直接**导出**为文件归档——纯文本格式，易于入库存档、随工单附走或做审计追溯。

## 历史会话

侧栏的**历史**页列出过往会话，可查看每条会话的详情并导出。产线场景下按设备序列号回查"这台机器当时配了什么"就在这里。

:::tip 历史按运行批次组织
历史列表聚焦当前这轮批量配置，切换批次可回看更早的记录。
:::

## 产线循环

结果页提供**配置下一台设备**按钮：一点回到扫描页，进入下一台设备的会话。重复"扫码 / 拿起下一台 → 连接 → 下发 → 回执"的循环，就是 NeoLinker 设计的主工作流。
